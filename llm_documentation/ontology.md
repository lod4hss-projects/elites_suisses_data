## Ontology used in the Elites Suisses KG

In the R2RML mapping from the PostgreSQL database to the KG we use application profiles defined in OntoME and referring to standard ontologies.

You can inspect as an example the profile [Person Identification
](https://ontome.net/profile/594) that provides basic identifiation elements for human beings like the birth date and standard/alternative names.

Profiles exported as OWL-DL XML files are available in the *llm_ontology* directory of this repo. If they are associated to the [Elites Suisses project](https://ontome.net/project/269/edit#profiles) they can be downloaded in just one file.
